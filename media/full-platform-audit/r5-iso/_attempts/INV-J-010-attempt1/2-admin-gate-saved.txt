Country activation corridors

Corridor currency and collection are one part of a country route. Compare them with the gateway and the jurisdiction on Country routes.

Corridors control collaboration collection, influencer payout onboarding, payout methods, and KYC for each country. Add a country from the list (full name + currency letters for a new payout profile). The collection route is a gateway saved on Payment gateways — for example Airwallex for Nigeria routes influencers to Airwallex setup, not Stripe Connect. KYC type is either KYC by Gateway or KYC by Document Upload. Group countries to keep this list short. An existing payout profile keeps the currency it already stored.

Also see Collaboration operations and Providers.

Country groups

Fold countries into a named group and choose one KYC type for that group. Saving writes the type onto every country in the group. Each country keeps its own currency and collection route, and you can change one country’s KYC type afterward.

Define the gateway and the government-ID details on KYC.

KYC by Gateway. The creator completes KYC with the payment gateway assigned for this corridor (for example Stripe Connect identity).
KYC by Document Upload. The creator uploads the configured identity documents and enters the required details (ID numbers, address, date of birth, and so on).
