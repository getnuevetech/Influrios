Complete business dashboard (finding 5)

  1. Order: Needs your attention → summaries → recent collaborations → start a request. Right column: billing, saved influencers, recent activity. Every card links to its destination page.
  2. Every attention row opens its item in a centered popup (desktop) or sheet (mobile), with the real decision buttons. It doesn't just link out.
  3. Collaborations badge 2 = response to review + content to review. Contracts badge 1 = agreement waiting for your signature. Attention shows 3 = 2 + 1, so each count sits on the item that opens it.
  4. Stats use the same projections as the destinations: Active requests = Collaborations › Requests; Agreements to sign = Contracts filter.
  5. “Discover Influencers” replaces “Discover Creators” in the sidebar and CTAs (Package 1 terminology).
  6. Funding/deposit actions stay out: live deposits closed. A fully signed agreement shows “Agreement signed · funding isn't available yet” with no task; Fund collaboration appears only when funding is available (master-spec §2.2c, DB8).
