Deduplication (Package 1 · from #533 INBOX-DUP-001)

  1. One row per task identity = (collaboration/funding id, milestone id or invitation id, action kind).
  2. Genuinely distinct tasks stay separate: Milestone 1 and Milestone 2 of the same collaboration are two rows.
  3. Repeated events for the same task (reminders, re-sent notices, status pings) merge into the one row. The row shows the latest date and “N updates”.
  4. When the task completes, the row leaves To do and the action-required flag clears on that task's notices. The notices stay in Notifications history, keeping their own read/unread state. Nothing is deleted, and unrelated unread messages or notices are not marked read.
  5. Counts: Collaborations badge and Needs your attention count deduplicated tasks, never raw notices.
  6. Acceptance A-INBOX-01: ≤ 1 open row per task identity; two distinct milestones never collapse.
  7. Shared example records: 4 rows = Collaborations badge 3 (invitation + 2 milestones) + Contracts badge 1 (Studio Tour Shorts) = home Needs your attention 4. Holiday Gift Guide isn't here: Amara already signed it.
  8. Mobile: Action inbox lives in the More drawer, so More is highlighted, not Dashboard. Every row keeps its Open / Review button.
