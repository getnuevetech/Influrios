Readiness rules (finding 3)

  1. Ready requires identity verified and the payout provider confirming payouts are enabled for the account. A saved bank account alone (accountOnFile) is not Ready.
  2. Verification pending: everything the user can do is done. Completed steps show as done. No “Complete setup” or “Continue” asks. Home shows a calm notice with no CTA, and the Earnings badge is 0.
  3. Action required names the one outstanding item and links straight to it. Steps already done stay done.
  4. Unsupported: no setup CTA, because there is nothing the user can do. Badge 0.
  5. Temporarily unavailable (provider unreachable): show the last confirmed state with its timestamp and Try again. Never fall back to Setup required, and never raise the badge.
  6. Earnings badge = 1 only for Setup required and Action required, and only while the user has active collaborations or unpaid earnings.
