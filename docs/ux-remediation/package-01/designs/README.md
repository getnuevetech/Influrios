# Package 1 visual boards

Standalone HTML boards, generated by [`_build/build.py`](./_build/build.py) from shared chrome ([`_build/chrome.py`](./_build/chrome.py)) so both roles use identical shell, icons and type. PNGs are rendered by [`_build/render.js`](./_build/render.js) into [`media/ux-remediation/package-01/`](https://github.com/getnuevetech/Influrios/blob/cursor/ux-pkg1-design-boards-9268/media/ux-remediation/package-01).

- Styles: [`_design-system.css`](./_design-system.css). Tokens are from `src/app/globals.css`, with Plus Jakarta Sans + Sora (no serif).
- Assets: [`assets/fonts/`](./assets/fonts/) (from `src/fonts`), [`assets/icons.svg`](./assets/icons.svg) (extracted from `src/components/icons.tsx`), [`assets/influencer-card-original.png`](./assets/influencer-card-original.png) (capture of the live demo card; implementation renders the component).
- Rule: application frames contain customer UI only. Notes sit outside the frames.
