# Influrios Product Strategy (source)

This folder holds working product strategy material.

The full **Product Strategy, Monetization & MVP Blueprint v2.2** (September 2026) was provided in the product discussion and is incorporated into:

→ [`../RECOMMENDATIONS_AND_EXECUTION_PLAN.md`](../RECOMMENDATIONS_AND_EXECUTION_PLAN.md)

### Locked from v2.2

- Platform brand: **Influrios** (do not use Influence Connect in production)
- Category: Influence Discovery & Collaboration Platform
- Positioning: “Find the right influence. Build the right collaboration.”
- Brand line: “Influence. Identity. Opportunity.”
- Card: standalone monetizable product; Starter = link only; Plus = shortlink + standard QR; Pro = dynamic QR
- Entitlements are admin-configurable launch defaults
- Onboarding: value before registration (draft → claim → verify → publish)
- MVP: discovery + card + collaboration before escrow/marketplace

If a PDF or marked-up export of v2.2 is added later, place it here as `PRODUCT_STRATEGY_v2.2.pdf`.
